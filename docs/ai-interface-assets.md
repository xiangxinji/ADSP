# AI 接口资产

在「项目 → 资产 → AI 接口」中集中登记项目使用的 AI 接口。此版本仅管理配置，
不会发起模型调用、检测 API Key 有效性或产生平台调用费用。

## 使用方式

1. 点击「添加 AI 接口」。
2. 选择或输入平台名称，例如 DeepSeek；支持其他自定义平台，不限定供应商列表。
3. 填写便于识别的接口名称和平台提供的 API Key，然后保存。
4. 通过「编辑」修改平台、名称或替换密钥。编辑时 API Key 留空表示保留原值。
5. 通过「删除」移除接口和密钥；操作前需要确认。

平台和名称为必填单行文本，各最多 100 个字符。名称在同一项目中唯一，ASCII
大小写不区分；不同项目可以使用相同名称。新建时 API Key 必填，最多 4096 个
字符，不能包含控制字符。字段首尾空白会被去除。PATCH 省略 `apiKey` 才表示保留；
显式传入空字符串、空白字符串或 `null` 会返回 `400`，不会清空旧密钥。

## 密钥安全

- 复用 ForgePilot 的 AES-256-GCM 密钥加密机制，SQLite 不存储 API Key 明文。
- API 只返回 `hasApiKey` 配置状态，不返回明文、密文或密钥片段；列表仅显示固定掩码。
- 编辑不加载旧密钥，关闭弹框清除已输入密钥，不写入浏览器持久化存储。
- 新增、替换密钥请求通过请求正文传输；远程部署必须使用 HTTPS 和受控访问。
- 本功能不新增认证或授权。当前仍是受控单租户预览，不应直接暴露到公共网络。
- 全局 `FORGEPILOT_CREDENTIAL_ENCRYPTION_KEY` / `FORGEPILOT_CREDENTIAL_KEY_PATH`
  和兼容的 `ASDP_*` 配置继续有效；备份/迁移时需保留对应加密密钥。
- 仅登记 AI 平台接口凭据，不要将 GitLab CI 或生产部署凭据放入此资产。

## Markdown 快捷引用

知识编辑器的 `/` 快捷菜单可按「AI 接口」、平台或接口名称搜索并插入引用：

```markdown
使用 [[ai-interface:接口资产ID]] 完成需求分析。
```

引用只携带资产 ID，显示名称和平台，不包含 API Key。只解析当前项目内的资产；
删除接口后引用显示为失效，原始 Markdown 不会被改写。

## 数据与操作边界

新表 `ai_interface_assets` 随服务启动幂等创建；旧项目无需迁移原有资产。
删除项目会级联删除所属 AI 接口。项目响应增加 `aiInterfaces`，项目统计增加
`aiInterfaceCount`，其他路径与已有字段不变。

API 路径见 [API 文档](api.md#ai-interface-assets)。资产操作目录显示编辑和删除，
两者均为客户端管理操作，不开放为工作流命令。后续模型调用需独立设计稳定操作
契约和供应商适配层，不能把密钥放入工作流输出或知识正文。
