# ForgePilot UI 尺寸规范

## 目标

ForgePilot 是高频使用的研发工作台。桌面端优先保证信息密度和扫描效率，移动端优先保证触控准确性。所有新页面和控件应复用 `app/assets/css/main.css` 中的语义尺寸变量，不在组件内新增无归属的高度、字号、间距或圆角。

## 基础规则

- 主要布局使用 4px 网格，2px 和 6px 仅用于图标校正、紧凑标签等微调。
- 桌面端默认表单控件高度为 32px，默认按钮可见高度为 28px，移动端交互热区不小于 44px。
- 控件尺寸通过 `sm`、`md`、`lg` 表达，不用 `small`、`normal`、`large` 等其它命名。
- 图标尺寸与控件尺寸联动，不在页面中为同级图标指定不同尺寸。
- 页面标题、区块标题、正文和辅助信息必须从统一字号阶梯中选择。
- 尺寸调整不能通过 `zoom`、`transform: scale()` 或修改浏览器缩放实现。

## 表单控件尺寸

| 规格 | 桌面高度 | 图标 | 字号 | 水平内边距 | 使用场景 |
| --- | ---: | ---: | ---: | ---: | --- |
| `sm` | 28px | 12px | 11px | 6px | 紧凑筛选、表格内编辑控件 |
| `md` | 32px | 16px | 12px | 8px | 默认输入框、选择框 |
| `lg` | 36px | 20px | 13px | 8px | 需要更高可读性的表单控件 |

## 按钮尺寸

按钮比同规格表单控件低 4px，避免操作按钮在工作台中显得笨重。

| 规格 | 可见高度 | 图标 | 字号 | 水平内边距 | 使用场景 |
| --- | ---: | ---: | ---: | ---: | --- |
| `sm` | 24px | 12px | 10px | 6px | 行操作、文字按钮、紧凑工具栏 |
| `md` | 28px | 16px | 11px | 8px | 默认按钮、弹框操作 |
| `lg` | 32px | 20px | 12px | 12px | 页面唯一的强调操作 |

在 760px 及以下视口，单行输入框和选择框的可见高度提升到 44px，输入文字不小于 16px，避免移动浏览器自动缩放。按钮保持紧凑的可见高度，但使用透明命中区域把实际触控热区扩展到至少 44px；相邻按钮之间至少保留 8px，避免命中区域重叠。

组件接口：

```vue
<AppButton size="sm">行操作</AppButton>
<AppInput size="md" />
<AppSelect size="md" />
<AppTextarea size="lg" />
<AppCheckbox size="sm" />
```

未指定 `size` 时，普通按钮和表单控件使用 `md`；`text`、`text-danger`、`plain` 按钮使用 `sm`。按钮图标会自动匹配当前尺寸，只有具有明确视觉原因时才允许覆盖 `icon-size`。

## 字号阶梯

| Token | 尺寸 | 用途 |
| --- | ---: | --- |
| `--font-size-xs` | 11px | 元信息、表格辅助信息、紧凑控件 |
| `--font-size-sm` | 12px | 次要正文、标签、默认按钮 |
| `--font-size-md` | 13px | 桌面端默认正文、默认输入文字 |
| `--font-size-lg` | 14px | 强调正文、编辑器正文 |
| `--font-size-xl` | 16px | 卡片标题、重要标签 |
| `--font-size-heading-sm` | 18px | 区块标题 |
| `--font-size-heading-md` | 24px | 次级页面标题 |
| `--font-size-heading-lg` | 28px | 一级页面标题 |

正文行高建议为 1.5-1.7。数字列、计数器和时间使用等宽数字特性，避免数值变化引起布局抖动。

## 间距阶梯

| Token | 尺寸 | 典型用途 |
| --- | ---: | --- |
| `--space-0-5` | 2px | 光学校正 |
| `--space-1` | 4px | 标签内部间距 |
| `--space-1-5` | 6px | 图标与文字间距 |
| `--space-2` | 8px | 紧凑控件和行内元素 |
| `--space-3` | 12px | 默认控件组、紧凑卡片 |
| `--space-4` | 16px | 默认卡片内边距 |
| `--space-5` | 20px | 区块内部间距 |
| `--space-6` | 24px | 区块之间、页面横向留白 |
| `--space-8` | 32px | 页面顶部和大区块间距 |
| `--space-10` | 40px | 编辑内容留白 |
| `--space-12` | 48px | 页面底部留白 |

## 圆角和布局

| Token | 尺寸 | 用途 |
| --- | ---: | --- |
| `--radius-sm` | 5px | 标签、代码片段 |
| `--radius-md` | 7px | 按钮、输入框、图标容器 |
| `--radius-lg` | 10px | 卡片、面板 |
| `--radius-full` | 999px | 状态胶囊、圆形按钮 |

全局顶部栏高度为 56px，内容最大宽度为 1180px。桌面页面横向留白为 24px，移动端为 16px；页面默认顶部留白为 32px，底部留白为 48px。

## 采用检查

新增或修改界面时检查：

1. 交互控件是否使用共享组件和 `sm`、`md`、`lg` 规格。
2. 页面中是否出现可由现有 token 表达的硬编码尺寸。
3. 同一层级的按钮、输入框和图标是否一致。
4. 375px、768px、1024px、1440px 视口是否无横向滚动和遮挡。
5. 移动端触控热区是否至少 44px，键盘焦点是否清晰可见。
